
### Persona
Ibu rumah tangga
Ibu rumah tangga membutuhkan sebuah sistem untuk merekam pengeluaran dan pemasukan ekonominya dengan mudah. Website ini dibuat untuk memenuhi kebutuhan itu. Website ini juga memiliki fitur amplop agar dapat membagi saldo ibu rumah tangga berdasarkan kebutuhan.

### Rancangan Struktur Data
{ id, nama, jatah }
Contoh: { id: "amplop-1", nama: "Belanja Dapur", jatah: 1500000 }

### Keputusan Desain
Data amplop dan transaksi dipisah agar tidak tercampur.
